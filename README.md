# 麦侦探 · mcd-deal-detective

**去麦当劳之前问一句：我想吃这些，怎么点最省钱？**

麦侦探是一个 WorkBuddy Skill。你只要说出门店（或位置）和想吃的东西，它会通过麦当劳中国官方 MCP 查这家店的实时菜单，把单点、套餐、套餐换选、双人/分享餐、可用优惠券、随单开卡这些点法都算一遍，用官方计价给出最多 3 个方案；你选好后，它帮你生成官方支付链接。

> 本项目为麦当劳程序员节创意开发大赛参赛作品，非麦当劳官方产品。

## 它能帮你做什么

- **你点名的一样不少**：说“2个汉堡、1份薯条”，方案里一定有这些；套餐顺带的可乐、薯条会写清楚“多送了什么”。
- **自动找最省的点法**：本地精确搜索所有套餐组合，再拿最有希望的几个去官方计价，以官方整单实付为准。
- **优惠自动算**：能领的免费券自动领、能用的券自动试；已经是会员就按会员价，随单开卡更便宜才会推荐开卡（卡费算在实付里）。
- **多花一点多一堆**：你说的数量是“至少”。如果多花的钱不超过多得东西单点原价的 1/5（比如多 1 元多一份 5 元的薯条，或多 12 元换成八件套、多得鸡翅薯条可乐和一张月卡；随单开的卡按 ¥5 算价值），会单独列出来让你决定。每个方案还会写“同样这些东西单点要多少、省了多少”。
- **只说类别也行**：“2个汉堡”会给出不同口味的方案让你挑。
- **确认后才下单**：你选定方案、确认价格后才创建订单，返回官方支付链接。

## 在 WorkBuddy 里用起来

**1. 连接麦当劳 MCP**

- 在 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 用手机号登录，控制台里申请 MCP Token。
- 在 WorkBuddy 的连接器里添加自定义 MCP，填入 [mcp-config.example.json](mcp-config.example.json) 的内容，把 `${MCD_MCP_TOKEN}` 换成你的 Token（[WorkBuddy 连接器说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Connector)）。

**2. 安装 Skill**

把整个项目文件夹放到 `~/.workbuddy/skills/mcd-deal-detective/`（需要包含 `SKILL.md`、`scripts/`、`references/`）：

```bash
git clone https://github.com/mc-zhangyang/mcd-deal-detective.git ~/.workbuddy/skills/mcd-deal-detective
```

电脑上需要有 Python 3.9 及以上版本（WorkBuddy 自带的也可以），不用装任何依赖。

**3. 直接说需求**

```text
西安长和卜蜂中心那家麦当劳，2个汉堡、几块麦乐鸡、2块鸡翅、一份薯条，怎么点最划算？
```

麦侦探会用并排卡片展示最多 3 个方案（下面是同样内容的表格示意，金额以官方实时计价为准）：

| | **方案1 · 最低实付** | **方案2 · 不开卡** | **方案3 · 换口味** |
|:--|:--|:--|:--|
| 实付 | **¥59.80** | **¥87.40** | **¥59.80** |
| 点法 | 全明星双人分享餐八件套＋随单开麦金卡体验卡（15天） | 人气经典随心配＋4 件单品 | 全明星双人分享餐八件套＋随单开麦金卡体验卡（15天） |
| 餐品 | **麦辣鸡腿汉堡×1** | **麦辣鸡腿汉堡×2** | **麦辣鸡腿汉堡×2** |
|  | **板烧鸡腿堡×1** | **麦乐鸡5块×1** | **麦乐鸡4块×1** |
|  | **麦乐鸡4块×1** | **麦辣鸡翅2块×1** | **麦辣鸡翅2块×1** |
|  | **麦辣鸡翅2块×1** | **中薯条×1** | **中薯条×1** |
|  | **中薯条×1** | 可乐麦炫酷×1 | 中薯条×1 |
|  | 中薯条×1 |  | 可乐中杯×2 |
|  | 可乐中杯×2 |  |  |
| 备注 | 含卡费¥9.90；同样这些单点要¥118.50，省¥58.70 | 同样这些单点要¥100.50，省¥13.10 | 含卡费¥9.90；汉堡选麦辣鸡腿汉堡×2；同样这些单点要¥117.50，省¥57.70 |

加粗是你点名要的，不加粗是套餐附带多送的。

🔍 **侦查过程**：翻了本店 131 款菜单；拆开 5 个套餐/随心配/双人餐看全部可选项；没有可领的新券，本店本单暂无可用券；分别按「不开卡」和「随单开麦金卡体验卡（15天）」算；本地精确比较了 280 种套餐组合（每种都配出最省选法）；挑出 10 个候选向麦当劳官方核价（10 个有效）。

💡 **结论**：只点你要的、全按最便宜的单点买要 ¥87.50；最省的方案 ¥59.80，少花 **¥27.70**。

选好后告诉它“要方案1，外带”，它会再核一次价，确认后下单并给你支付链接。

## 说明

- 默认到店自取，一次计算一家门店、一笔订单、默认做法；不涉及外送、积分、拆单。
- 结果是“这家店此刻最省的点法”，价格、库存、券以麦当劳官方实时返回为准。
- 不会在未确认时下单或付款；Token 只保存在你的 WorkBuddy 连接器配置里。
- 技术细节见 [SKILL.md](SKILL.md)、[references/solver-interface.md](references/solver-interface.md)、[MCP_INTEGRATION.md](MCP_INTEGRATION.md)。
